## 方向书

写出 Product（谁用它完成什么）、Character（2–3 个能指导选择的具体词）、World（业务所属场景或材料）、Moments（1–2 个真正需要视觉强调的位置）、Signature（一个在产品中可持续复用的细节）。每项都要指出来自真实产品的依据及对应的本地 token/组件。已有品牌和中文内容优先，外部示例只借方法，不复制颜色、logo、字体、文案或布局。

## 九轮

方向确定后先按 [design-plan.md](design-plan.md) 形成蓝图与执行项，再复核九轮。每轮按“现状证据或新页目标 → 目的 → 计划 ID / owner / 改动 → 检查结果 → 保留或跳过理由”记录；允许一轮无改动。大面积改写可以一次落代码，但审查仍逐轮覆盖。

1. **Spacing：** 检查分组、留白、对齐、表格列和数值基线；用项目间距尺度。
2. **Color：** 检查语义层级、状态颜色和对比度；保留品牌色，不套外部禁色表。
3. **Icons：** 检查图标含义、尺寸、笔画与文字角色；保留既有图标系统。
4. **Copy：** 检查操作词、数据单位、比较对象、真实声明和中文断行；不编造产品事实。
5. **Type：** 基于实际文案处理字号、行高、字重和中英数字混排；以可读性和本地字体为准。
6. **Layout：** 检查信息顺序、内容密度、主任务、宽窄屏和长文本；保持功能入口可达。
7. **Details：** 核对边框、圆角、焦点、选中、悬停、表头和状态细节，避免散落特例。
8. **Visuals：** 仅在内容需要时加入产品预览、真实图表、对象或场景，见 [visuals-and-effects.md](visuals-and-effects.md)。
9. **Motion：** 只为反馈、状态与方向添加动效；验证 reduced motion 和低性能设备。

编号表示复核覆盖顺序，不限制实现依赖。新页或结构重塑先确定内容事实与布局，再定排版、间距和颜色；先使页面静态可用，再加入素材和动效。已有页的重排必须遵守蓝图中的授权和入口保留约束。固定 4px 网格、限制字重或渲染次数不作为通用规则。
