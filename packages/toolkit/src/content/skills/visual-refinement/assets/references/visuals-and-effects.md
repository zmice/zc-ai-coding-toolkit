# 素材与可选效果

来源：Damir Sokolovsky，`unslop` 的 visuals/effects 方法，固定提交 `97daa3eb365670ea3f87ed85356cbfcee18105a5`，CC BY 4.0；本文为产品契约优先的改写。许可和变更声明见 [LICENSE-unslop.txt](LICENSE-unslop.txt)。

先判断页面是否需要视觉素材。后台、设置页可能只需真实数据层级；首页或空态可能适合产品预览。按任务从真实产品预览、图表、单个对象、场景中选一种主视觉，并说明它证明了哪项产品主张。图表保持指标、单位、系列语义；演示数据必须标明，不把生成图片里的 UI 说成可操作界面。

需要生成素材时，先写一句具体场景，再组成 prompt：主体、场所、光线和本地色板、风格、构图留白、排除文字/logo/UI、目标比例和尺寸。调用宿主已有图像能力；保留素材来源及项目使用权信息。不强制新服务，也不因上游示例要求重复征求已给出的授权。没有图像工具时，可交付真实产品预览或其他完整方案；若素材确实未完成，明确列为未完成，不把空槽当成成品。

需要效果时可考虑 glyph、网点、抖动或双色处理，但仅用于符合方向书的重点素材。避免把示例效果铺到控件。Canvas/动画实现必须按组件生命周期清理 observer、timer 与 animation frame；页面隐藏时暂停，遵守 reduced motion，控制图片大小、绘制成本与加载优先级。为有意义图像给替代文本，为纯装饰正确隐藏语义；验证对比度、裁剪、窄屏和 200% 缩放。
