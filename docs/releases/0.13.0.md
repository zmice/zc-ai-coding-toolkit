# 0.13.0

本版将实验性 Unslop 设计能力接入 `start` 全流程，覆盖新页面设计与已有页面重塑。对外发布包仍只有 `@zmice/zc`。

## 行为与兼容性

- `start` 自动判断设计任务；无需点名视觉技能。新页面或较大重塑形成产品方向、页面蓝图和实施计划，spec、plan、build 与浏览器 QA 沿用同一设计契约和任务 ID。
- 小范围修复、纯后端、只读审查与只出方案保留各自边界；已有设计方案继续执行，不重复要求确认。直接进入 spec/plan/build 也保留设计上下文兜底。
- 操作型页面要求首屏能够开始主要任务；优先清理重复标题和说明，不强求整个长表单同屏。
- 静态视觉切片使用相称检查与浏览器验收；可自动断言的行为变化继续采用 TDD。
- 快照默认移除 hidden/password/file 表单值。快照仍不是通用净化器，分享前需要检查敏感信息。
- 新增仓库侧原生设计评测入口，冻结技能和合成输入，拒读评分答案及宿主私人指令；无效捕获或清理未确认返回非零状态。评测工具不进入插件运行时。

## 已验证与已知限制

新页、重塑页及新规则下独立新页样本均完成真实 Chrome 桌面/窄屏验证，覆盖首屏任务入口、提交校验、筛选、权限、失败重试、数据保持及焦点恢复。隔离 npm 安装与原生插件技能发现通过。

原生 Codex 首轮对照完成一组；其余批量用例在 Windows 沙箱初始化阶段超时，尚无有效模型结果。此能力继续标记 experimental。合成页面验证不替代真实业务验收，也不代表完整 WCAG 审计；详细证据和边界见 [生命周期验证记录](../../references/notes/unslop-lifecycle-validation-2026-11-13.md)。

## 升级

```sh
npm install --global @zmice/zc@0.13.0
zc platform plugin codex --upgrade --with-agents --plan --json
zc platform plugin codex --upgrade --with-agents --json
zc platform plugin codex --status --with-agents --json
```

检查插件版本、enabled 状态和 companion 回执；新线程加载新版技能。已禁用的插件应保持禁用。先在实际业务页面验证设计与交互，再扩大使用范围。

## 回退

升级前备份受管配置、agents 和安装回执。发现加载、配置或流程回归时，安装 `@zmice/zc@0.12.0`，并按备份或已验证的 marketplace 提交恢复插件；仅降级 CLI 不会降级插件。不要手工修改缓存或执行 npm unpublish。
