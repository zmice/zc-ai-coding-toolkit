# 0.11.1

本版收敛子代理上下文预算与审查覆盖，更新受管 Codex 模型分工，并修复 worktree 锁释放时偶发的路径检查失败。

## 行为与兼容性

- 普通子任务默认 GPT-6 Sol/medium；审查、架构、安全、性能为 Sol/high；轻量研究与上下文维护为 GPT-6 Luna/high。
- 用户已有默认模型保持不变；仅更新仍匹配安装回执的受管默认值。主任务模型与 service tier 不变。新角色配置需新任务加载。
- 小型机械修改按风险选择自审与 controller 检查；复杂/高风险变更保留独立审查。增加可调整的读取/输出预算、任务内检查点与无进展停线。
- 审查记录固定 diff、完整变更清单、逐文件状态与证伪证据；排除文件和零 finding 不能冒充完整覆盖。
- 不引入 OCR 运行时依赖，不改变 CI 门禁。模型合成小样本没有证明普遍速度、质量或额度收益。
- agent 同步发生普通写入异常时恢复并核验配置/回执，避免重试丢失默认字段所有权；恢复失败会报错。此保护不保证进程被终止或断电后的原子性。

## 升级

```sh
npm install --global @zmice/zc@0.11.1
zc platform plugin codex --upgrade --with-agents --plan --json
zc platform plugin codex --upgrade --with-agents --json
zc platform plugin codex --status --with-agents --json
```

验收要求：插件版本 0.11.1、`overallStatus=complete`、agents `up-to-date`，missing/drifted 均为 0；另检查新任务实际 skill 路径和角色日志，不能只凭文件存在断言运行态已重载。

## 回退

升级前备份 Codex 配置、受管 agents 与安装回执。发生配置解析、插件加载或关键流程回归时停止推进，安装 `@zmice/zc@0.11.0`，恢复对应备份并复核非受管配置。插件按官方 Git marketplace 流程固定到先前已验证提交再安装；仅降级 CLI 不会降级已安装插件。不要手工改插件缓存或执行 npm unpublish。
