# 0.12.0

本版新增按需视觉重塑能力，完善 Codex 插件状态、上游治理和技能评测。对外发布包仍只有 `@zmice/zc`。

## 行为与兼容性

- 新增实验性 `$zc-toolkit:visual-refinement`：基于实际证据选择重塑、精修、无需修改或补证据，形成产品方向并执行九轮检查。复用既有 UI 实现、审查和浏览器 QA；功能修复不强制进入重塑。
- 附带可选 snapshot/story 脚本及 Unslop CC BY 4.0 来源许可。依赖由使用者按环境准备，脚本不自动安装。快照不是净化器或完全离线导出；视频不是产品验收。
- Codex、Qwen、OpenCode、Qoder CN 分发新技能附件；当前 Claude 适配器不生成 skills。
- Codex 插件状态分别报告 installed、available、enabled。disabled 或未知启用状态不会被升级动作意外重新启用；保持既有安装默认值，portable 清单为显式可选。
- 上游批量采集保留完整结果与失败计数；显式 strict 模式将部分采集失败作为非零结果。Review 保留同路径不同变更层身份，并在首次补丁读取前禁用 external diff/textconv。
- 新增技能分发身份审计、上下文体量审计和隔离首轮行为评测。模型首轮微测未证明完整业务界面的视觉改善，因此新技能继续标记 experimental。

## 升级与验收

```sh
npm install --global @zmice/zc@0.12.0
zc platform plugin codex --upgrade --with-agents --plan --json
zc platform plugin codex --upgrade --with-agents --json
zc platform plugin codex --status --with-agents --json
```

检查插件版本、enabled 状态、companion 回执和实际技能路径；新线程加载新版能力。已有禁用插件应保持禁用。先在真实产品的一个任务面试用视觉技能，分别记录截图、交互和自动检查，不把打包或生成成功当作业务验收。

## 回退

升级前备份受管配置、agents 与安装回执。出现插件加载、配置解析或既有流程回归时停止升级，安装 `@zmice/zc@0.11.1`，按对应备份和已验证 marketplace 提交恢复插件；仅降级 CLI 不会降级插件。不要手工修改缓存或执行 npm unpublish。

发布验证与各渠道状态另记录于本轮发布回执；本文不把尚未完成的发布视为成功。
