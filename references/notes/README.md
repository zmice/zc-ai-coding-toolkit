# Notes Semantics

`references/notes/` 是上游治理的工作日志层。

适合记录：

- sync 摘要
- review 发现
- 迁移取舍
- 未决问题
- 上游变化与下游影响之间的对应关系

规则：

- `notes` 可编辑，可随着审阅推进持续修订
- `notes` 可以概括某次 snapshot，但不是 snapshot 本身
- 每个 upstream 最好只有一个清晰的主 note 文件，便于从 `references/upstreams.yaml` 追踪
